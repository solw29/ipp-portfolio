# Hero·About 문구 변경 전후 화면 비교

검사일: 2026-11-20 KST. 기존 커밋 `cecf0a1`과 문구 변경 작업 트리를 각각 프로덕션 빌드해 Chromium에서 비교했습니다. 화면 너비는 320·390·768·1440px, 높이는 1000px입니다. 글꼴 로딩 후 Reduced Motion을 적용해 애니메이션 중간 프레임을 제외했습니다.

## 유지된 크기와 스타일

- 기존 글자 크기·행간·폰트·굵기·자간·패딩·테두리 반경이 동일합니다.
- 이름·직무·About 제목, 헤더, Hero 버튼, 코드 프로필 패널의 크기가 동일합니다.
- 15개 기술 카드·아이콘·기술명, 6개 프로젝트 카드·이미지·제목·배지, 타임라인 제목과 Contact 제목의 크기가 동일합니다.
- DB 보조 설명은 삭제됐지만 기술 카드 크기는 유지됐습니다.
- 모든 비교 화면에 가로 넘침이 없습니다.
- 기존 스타일시트는 보존하고 How I Work 전용 규칙만 추가했습니다. 커서·트레일·내비게이션·프로젝트 데이터 및 자료는 변경하지 않았습니다.

## 문구와 신규 영역에 따른 자연스러운 차이

문장 길이가 달라졌으므로 설명문의 줄 수·본문 높이와 그 다음 요소의 세로 위치까지 완전히 같다는 의미는 아닙니다. 글자나 기존 컴포넌트를 확대·축소한 변경은 없습니다.

| 너비 | Hero 높이: 전 → 후 | About 높이: 전 → 후 |
|---|---|---|
| 320px | 1007.9 → 1007.9px | 1083.0 → 1781.3px |
| 390px | 991.2 → 991.2px | 1027.0 → 1605.5px |
| 768px | 780.0 → 780.0px | 941.0 → 1575.8px |
| 1440px | 924.0 → 924.0px | 844.6 → 1232.7px |

Hero 전체 높이는 모두 같습니다. 768·1440px의 Hero 설명문은 줄 수가 줄었으며, About 본문 역시 새 문구에 맞춰 높이가 달라졌습니다. About 전체 높이 증가는 이전 요청에서 추가한 How I Work의 제목·세 항목·간격을 포함한 결과입니다. 모바일에서는 세 항목을 한 열로 표시합니다.

About 왼쪽 제목은 그대로 두었고, 제공된 수정안에 반복된 첫 문장은 한 번만 표시합니다. DB의 `SQL 기반 데이터 조회 및 관리` 보조 문구는 제거했습니다.

[측정 JSON](copy-layout-review.json)에는 문구 높이 차이와 섹션 크기를 기록했습니다. `unexpected`는 빈 배열입니다. 캡처와 원본 비교 빌드는 로컬 `test-results/layout-comparison/` 및 `/tmp/portfolio-copy-baseline/`에 보관하며 Git에는 올리지 않습니다. 최신 운영 검증은 [Actions](https://github.com/solw29/ipp-portfolio/actions/workflows/live-browser-test.yml)의 배포 SHA와 결과를 함께 확인합니다.
