# SW개발 직무 중심 문구 및 공개 연락처 정리

Graphite Cyan 디자인, 커서, 카드 Glow, 스크롤 등장, 메뉴, 필터와 상세 페이지 구조는 유지했습니다. 회사 지원 문구는 기본 비표시로 두어 일반 공개 포트폴리오로 사용합니다.

## 주요 문구 전후

| 영역 | 변경 전 | 변경 후 |
|---|---|---|
| Hero | 데이터를 다루고, 기능을 구현하며, 결과를 검증합니다. | 데이터를 실제로 작동하는 기능으로 연결합니다. |
| Hero 보조 | 전공·웹 프로토타입·모델 실험을 나열 | 웹 화면과 외부 API를 연결하는 개발부터 데이터 처리·모델 실험까지, 직접 구현하고 검증한 경험을 쌓아왔습니다. |

카드의 SCOPION 화면/API 흐름, 개인 PyTorch 비교 평가, 쇼핑 QA의 근거 상태 분류·답변 품질 비교, 주택 가격예측 모델·도시별 비교를 요청 문구로 정리했습니다. My Role은 기존 근거를 유지하며, 카드 요약을 팀 전체 프로젝트 설명과 개인 담당 범위로 나누어 읽을 수 있게 했습니다.

## 보존 및 검증

- Skills 데이터의 5개 카테고리·15개 기술이 이전 커밋과 일치함을 데이터 비교로 확인했습니다. Oracle은 같은 DBMS의 정식 표시명인 Oracle Database로 표시하며 중복 카드를 추가하지 않습니다.
- 각 프로젝트의 날짜, 팀 정보, 역할, 기술, 결과, 한계, 업무 목록과 데이터 흐름을 이전 버전과 비교해 보존했습니다.
- `src/style.css`, `src/main.ts`, `src/cursor.ts`, `src/skill-icons.ts`, `src/experiment-results.json`의 SHA-256이 변경 전과 같습니다.
- 공개 데이터에서 연락처 필드와 관련 설정·조건부 출력 코드를 제거했습니다. 문서의 오래된 공개 설정 안내도 정리했습니다.
- `scripts/check-public-content.mjs`는 현재 소스·HTML·JavaScript·JSON·문서에서 개인 연락처 값, 링크와 폐기된 출력 설정을 검사합니다. CI에서도 빌드 직후 실행합니다.
- 기존 문서 이미지와 영상의 71개 이미지/표본 프레임을 OCR로 점검했습니다. 과거 브라우저 녹화는 현재 연락처 정책과 혼동하지 않도록 삭제하고 최신 Actions 영상 링크로 대체했습니다. 실제 프로젝트 시연 영상과 연구 자료는 변경하지 않았습니다.
- 이 정리는 현재 저장소 파일과 배포 산출물 기준입니다. 과거 Git 커밋의 이력 자체는 재작성하지 않았습니다.

Spring Boot, Kotlin, React, Next.js 또는 MySQL 기반 서비스 구현 경험을 새로 추가하지 않았습니다. 특정 회사의 예약 업무를 수행한 것처럼 연결하지 않았습니다.

## 추가 제공 자료의 시각화

PDF 전체나 슬라이드를 그대로 첨부하지 않고 필요한 연구 그림만 사용했습니다.

| 자료 | 반영 방식 | 해석 범위 |
|---|---|---|
| 기계학습 6조(수정본), 20쪽 | 도시별 성능 비교 그래프 영역만 고해상도로 발췌. 기존 주택 카드의 프레임·텍스트·인터랙션을 유지하고 시각 자료만 교체 | 원본 팀 그래프의 축·범례·수치를 바꾸거나 새 성능 지표를 만들지 않음 |
| 같은 보고서 23쪽 | 서울 SHAP 막대·비율 그래프 영역을 발췌해 상세 자료 갤러리에 추가 | 팀 자료의 해석 예시. 개인 단독 성과로 표현하지 않음 |
| 제공된 BRITS/TCN 도식 | 학습 비교 분기만 이미지 편집 도구로 Graphite Cyan 형태로 재구성하고 수동 검수 | Common BRITS checkpoint → Pair-control / Proposed, 고정 TCN-A의 보존 손실은 Proposed에만 추가. 설명용 재구성이며 전체 파이프라인·팀 최종 결과가 아님 |

BRITS 이미지의 추가 손실 관계와 분기·화살표를 확인했고, 성능 수치를 넣지 않았습니다. 개인 3개 시드 AUPRC·MAE·Recall 결과와 실제 CSV 차트는 그대로 유지했습니다. 이미지에는 대체 텍스트, 출처·성격을 구분하는 캡션, 원본 크기 보기 링크가 있습니다.

## 실행한 테스트

- `npm run build`: TypeScript·정적 생성·번들링 통과.
- `npm run check:public`: 공개 소스·산출물·문서 검사 통과.
- 로컬 프로덕션 Chromium: 15개 Skills, 카드·필터, 내비게이션, 커서·트레일·리플·스크롤, 상세 4개 경로와 신규 이미지 디코딩, AUPRC 실제 표, 모바일 키보드 메뉴, 터치·Reduced Motion, 이메일 링크·주소 복사 검사 통과.
- Contact는 이메일·GitHub 두 행만 있으며 모든 경로에서 공개 연락 링크·값 검사를 통과했습니다.
- 브라우저·콘솔·사이트 자원 HTTP 오류가 없습니다.
- 실사이트 결과와 영상은 [GitHub Actions](https://github.com/solw29/ipp-portfolio/actions/workflows/live-browser-test.yml)의 해당 커밋 실행에서 확인합니다. 로컬 결과를 실사이트 성공으로 대신 보고하지 않습니다.
